# История изменений

## [1.0.0] - 2025-12-19

### ✅ Реализовано

- **Telegram бот** с полным FSM-флоу сбора заявок
  - Команда /start с главным меню
  - Выбор типа мебели
  - Загрузка фото (1-10 фото)
  - Ввод района
  - Валидация и нормализация телефона
  - Автоматическая отправка заявок менеджеру

- **Веб-админ-панель** на Flask
  - Список всех заявок с пагинацией
  - Детальный просмотр заявки
  - **Отображение фото** через Telegram Bot API
  - Статистика по типам мебели

- **База данных** SQLite
  - Хранение заявок
  - Хранение состояний FSM

- **Интеграция с Telegram**
  - Отправка заявок в группу менеджеров
  - Отправка фото медиа-группой

### 🔧 Технические детали

- Python 3.13 совместимость
- aiogram 3.23.0
- Flask 3.1.2
- SQLite для хранения данных
- Асинхронная обработка запросов

### 📝 Документация

- README.md с полной инструкцией
- SETUP.md для быстрого старта
- TESTING.md с чек-листом тестирования
