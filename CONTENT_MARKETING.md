# Контент-маркетинг: Автоматическая публикация в Telegram-канал

## Описание

Реализована система для автоматической публикации контента в Telegram-канал:
- **Кейсы** - истории диванов с описанием работ, материалами, ценой и отзывами
- **Посты "из цеха"** - фото/видео с производством, мастерами и оборудованием

## Настройка

### 1. Добавить CHANNEL_ID в .env

Добавьте в файл `.env` ID вашего Telegram-канала:

```env
CHANNEL_ID=@your_channel_username
# или
CHANNEL_ID=-1001234567890
```

**Как получить ID канала:**
- Для публичного канала: используйте @username (например, `@peretiazhkoff_channel`)
- Для приватного канала: используйте числовой ID (например, `-1001234567890`)
  - Добавьте бота в канал как администратора
  - Отправьте любое сообщение в канал
  - Используйте бота @userinfobot для получения ID канала

### 2. Добавить бота в канал

1. Откройте настройки канала
2. Перейдите в "Администраторы"
3. Добавьте бота как администратора
4. Дайте боту права на публикацию сообщений

## Использование

### Управление кейсами

1. Откройте админ-панель: `http://your-server:5000/admin`
2. Перейдите в раздел **"Кейсы"**
3. Нажмите **"+ Создать кейс"**

**Заполните форму:**
- **Название кейса** - заголовок (обязательно)
- **Что было** - описание состояния мебели до работы
- **Что сделали** - описание выполненной работы
- **Тип ткани** - использованная ткань
- **Тип наполнителя** - использованный наполнитель
- **Стоимость** - цена работы в рублях
- **Отзыв клиента** - отзыв клиента
- **Фото** - file_id фото из Telegram (по одному на строку)

**Как получить file_id фото:**
1. Отправьте фото боту @peretiazhkoff_bot
2. Бот сохранит file_id в заявке
3. Скопируйте file_id из базы данных или используйте специальный бот для получения file_id

4. Нажмите **"Создать кейс"**
5. На странице кейса нажмите **"Опубликовать в канал"**

### Управление постами "из цеха"

1. Перейдите в раздел **"Из цеха"**
2. Нажмите **"+ Создать пост"**

**Заполните форму:**
- **Название поста** - заголовок (обязательно)
- **Описание** - текст поста
- **Тип медиа** - фото или видео
- **File ID медиа** - file_id фото/видео из Telegram

3. Нажмите **"Создать пост"**
4. На странице поста нажмите **"Опубликовать в канал"**

## Формат публикации

### Кейсы

При публикации кейса в канал формируется пост со следующей структурой:

```
**Название кейса**

**Что было:**
[описание до]

**Что сделали:**
[описание после]

**Материалы:**
Ткань: [тип ткани]
Наполнитель: [тип наполнителя]

**Стоимость:** [цена] ₽

**Отзыв клиента:**
«[отзыв]»

#Перетяжкофф #ПеретяжкаМебели #РостовНаДону
```

Если есть фото, они отправляются медиа-группой с текстом в первом фото.

### Посты "из цеха"

При публикации поста "из цеха" формируется пост:

```
**Название поста**

[описание]

#Перетяжкофф #ИзЦеха #Производство
```

Медиа (фото/видео) отправляется вместе с текстом.

## Автоматическая публикация

Для автоматической публикации по расписанию можно использовать cron или планировщик задач:

```python
# Пример: публикация неопубликованных кейсов каждый день в 10:00
import asyncio
from database import get_all_cases
from content_publisher import publish_case_to_channel

async def auto_publish_cases():
    cases = await get_all_cases(published_only=False)
    for case in cases[:1]:  # Публикуем по одному в день
        if not case['published']:
            await publish_case_to_channel(case['id'])
            break

# Запуск через cron или планировщик
asyncio.run(auto_publish_cases())
```

## Решение проблем

### Ошибка "CHANNEL_ID не установлен"

Добавьте `CHANNEL_ID` в файл `.env` и перезапустите бота.

### Ошибка "Chat not found"

- Убедитесь, что бот добавлен в канал как администратор
- Проверьте правильность CHANNEL_ID
- Для приватных каналов используйте числовой ID, а не @username

### Ошибка "Not enough rights"

Убедитесь, что у бота есть права на публикацию сообщений в канале.

### Фото не отображаются

- Проверьте правильность file_id
- Убедитесь, что file_id не устарел (file_id действителен ограниченное время)
- Для долгосрочного хранения используйте сохранение файлов на диск

## Дополнительные возможности

### Получение file_id через бота

Можно создать специальный обработчик в боте для получения file_id:

```python
@router.message(F.photo | F.video)
async def get_file_id(message: Message):
    if message.photo:
        file_id = message.photo[-1].file_id
    elif message.video:
        file_id = message.video.file_id
    
    await message.answer(f"File ID: `{file_id}`", parse_mode="Markdown")
```

### Массовая публикация

Для публикации нескольких кейсов подряд:

```python
async def publish_multiple_cases(case_ids: List[int]):
    publisher = ContentPublisher()
    try:
        for case_id in case_ids:
            await publisher.publish_case(case_id)
            await asyncio.sleep(2)  # Пауза между публикациями
    finally:
        await publisher.close()
```
